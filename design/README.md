source of truth for the app. The token JSON here is the design-side record that
it is checked against; `apps/app/src/theme.test.ts` enforces the contrast and
surface rules.

## The rule most likely to be broken

Colour has three separate jobs: **domain** = what it measures (data only,
constant per measurement), **brand** = selection and primary action, **alert** =
risk (once per screen, never personalised). Clay is reserved for + Log. A change
that mixes them is wrong regardless of how it looks. Second most likely:
coloured deltas. There are none — change is a signed number in ink, in a
sentence.

user-selectable OKLCH accent. Read it for rationale only.
